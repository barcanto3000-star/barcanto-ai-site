## Cloudflare Pages quick path

1. Create a Cloudflare Pages project for this static folder.
2. Deploy the folder contents as the site root.
3. Add custom domain `barcanto.ai`.
4. Let Cloudflare issue HTTPS certificate.
5. Confirm DNS records point to the Pages project.
6. Verify public URLs:
   - `https://barcanto.ai/`
   - `https://barcanto.ai/privacy.html`
   - `https://barcanto.ai/terms.html`
   - `https://barcanto.ai/tiktokWuHCOtIQQmStvGPmBxaJvTKGicsgdl5W.txt`
7. Only after those pass: click TikTok Developer Center Verify.
